Tez-tez verilən suallar

1. İmtahan nəticələrimi necə yoxlaya bilərəm?
Cavab: Sistemdəki formu dolduraraq imtahan növünü seçmək, şagirdin ID nömrəsinin son 6 rəqəmini daxil etmək, daha sonra "Nəticəni Axtar" düyməsinə klikləmək kifayətdir.
2. Şagird ID-ni haradan tapa bilərəm?
Cavab: Şagird ID imtahana buraxılış vərəqində qeyd olunan 9 rəqəmli ədəddir. Nəticəni yoxlamaq üçün ID nömrənin son 6 rəqəmini qeyd etmək kifayətdir.
3. Nəticələrimi çap edə və ya yükləyə bilərəmmi?
Cavab: Bəli, nəticə tapıldıqdan sonra "Yüklə" düyməsinə klikləyərək nəticələrinizi yükləyə bilərsiniz.
4. Əgər nəticə tapılmasa nə etməliyəm?
Cavab: Əvvəlcə ID nömrənizi və imtahan növünü düzgün daxil etdiyinizdən əmin olun. Problem davam edərsə, məktəb ilə əlaqə saxlayın.
5. Hansı imtahanların nəticələri elan edilmişdir?
Cavab:
  • Diaqnostik qiymətləndirmə (III-IX siniflər)
  • Kiçik Summativ Qiymətləndirmə-1 (III-VIII siniflər)
  • Mövzu Sınağı-1 (IX sinif)
  • Kiçik Summativ Qiymətləndirmə-2 (III-VIII siniflər)
  • Mövzu Sınağı-2 (IX sinif)
  • Kiçik Summativ Qiymətləndirmə-3 (III-VIII siniflər)
  • Mövzu Sınağı-3 (IX sinif)
  • Kiçik Summativ Qiymətləndirmə-4 (III-VIII siniflər)
